    Operations

    01

    Interactive tile placement

    Create an editable copy of the displayed coordinate system.

    The new coordinate system becomes active immediately for interactive placement.

    Manual placement
    Alt + drag
    Move a tile within the plane of the view.
    Ctrl + Alt + drag
    Turn a tile about its centre, in that same plane.

    Orthogonal views only. The tile under the pointer is the one that moves; where tiles overlap, the one selected in the views list does. The new placement is saved when you release.

    Apply to channels

    This data has no channel axis.

    Apply to tiles

    With nothing selected, a drag moves the topmost tile under the pointer. Click a tile in the viewer or a view in the list to select it; Ctrl+click (⌘ on macOS) either one to select several: a drag then moves them all together, and a rotation turns each about its own center.

    Apply to timepoints

    This data has no time axis.

    02

    Registration

    Align all loaded views from the displayed coordinate system.

    Layers to register

    Select a layer by clicking it in the viewer or in the loaded views list. Hold Ctrl (⌘ on macOS) while clicking to select several layers. Unregistered layers keep their current placement under the new transform.

    About

    multiview-stitcher

    Registration and fusion for tiled, multiview microscopy data—running locally in your browser.

    Your data stays local.Images are processed on this device and are never uploaded.

    Built with Neuroglancer, OME-Zarr, and Pyodide.

    Runtime information will appear after startup.
